   `signups-cold-2026-08` (Leads objective), ad set `broad-v1`, ad `solveit-reel-v1` with the

2. **The four paywall checks are CLOSED, verified 2026-08-20 with a real card.** Firestore
   rules probe-locked (subscription is client-read-only), webhook created/updated/deleted all
   observed writing, APP_URL corrected, unlock path proven. Flipping `PAYWALL_LIVE_AT` in
   landing.html is now a business decision. Future-dated moment only, never backdated, for
   the reason SESSION-2026-08-09 explains.

3. **The card test found two live bugs.** First, APP_URL in functions/.env pointed at
   quanticaedu-a077d.web.app, so Stripe returned the buyer to the wrong origin: signed out,
   stale localStorage, no pixel. Fixed by the founder in .env plus a canonical-host redirect
   at the top of landing.html and paths/landing.html that bounces both default Firebase
   domains to quanticaedu.com preserving path, query and hash. Second, Stripe delivered
   subscription events out of order: updated (active) applied first, then created
   (incomplete) arrived late and overwrote paid back to inactive, every delivery a green 200.
   functions/index.js now writes through a transaction keyed on event.created (`eventTs` in
   the doc) and drops anything older than what is applied. The founder deployed functions
   himself; this repo still never does.

4. **The governing lesson of the whole session: presence is not reachability.** Five real
   bugs shared one shape, code that existed and never ran. `fbTrack('CompleteRegistration')`
   existed while an early `?signin=1` return above it meant no signup was ever recorded from
   the primary path. The Purchase handler existed in a file Stripe never sent buyers to. The
   onboarding safety net re-opened the modal in cases launch() refused because the guards
   lived in one place and not the other. The signed-out "Sign in" button rendered into
   `#authNav`, an element that does not exist. `_applyAccess` called `renderDashboard` across
   script-block scope and threw on every signed-in boot, killing the unlock listener. When
   verifying anything, trace from a real entry point to the line and say RUNS, not exists.

## The money path, exactly as verified

Subscribe → `startCheckout` (refuses while paywall off unless `?paytest=1` is in the URL;
releases `__checkoutStarted` when parking a plan for sign-in) → `createCheckoutSession` →
Stripe (live mode, $14.99) → return to `APP_URL` = `https://quanticaedu.com/landing` →
`?payment=success` fires Purchase with the plan read from `qa_plan` localStorage (24h window,
no value rather than a wrong value on fallback) → webhook writes
`users/{uid}/state/subscription` through the eventTs transaction → onSnapshot flips
`window._access` in place. Firestore rules: client may read subscription, never write it;
profile doc and `state/*` otherwise read-write for the owner only. The rules live only in
the Firebase console; CLAUDE.md records their shape.

Note for testing on the founder's machine: his network intermittently kills Firestore's
Listen channel with QUIC protocol errors, so mid-session onSnapshot pushes may not arrive
for HIM. Page-load reads always work. Do not chase this as an app bug.

## Onboarding, guest flow, design

- Onboarding v2 (`quantica.onboarding.v2`): two questions (who, level), opens from launch()
  under the boot gate so nothing flashes, session-scoped skip, Escape/Back/backdrop close it,
  `Onboard.shouldAutoOpen()` is the single decision both triggers call. `FLOW='off'` is the
  kill switch. It never covers deep links or anyone with progress, and go() keeps a visitor
  on the lesson they came for.
- Guests are first-class: `__exitToHome` keeps signed-out users on the in-app dashboard
  because paths/home.html bounces them to the marketing page. The sitebar shows a real
  Sign in button for guests (`sbAcct` slot); the auth modal dismisses by tapping outside the
  card (a "Maybe later" link is noted polish, unbuilt).
- Design rules enforced everywhere now including paths/home.html: Chillax display and body,
  Space Grotesk small labels, border-radius 0 except true circles, no all-caps labels, no
  em-dashes anywhere, separators are middle dots. paths/home.html was restyled this session
  (Fraunces and Inter removed). Per-course palettes and mascots are intentional, leave them.
- `build_lessons.py` stamps `live:true` per lesson into `data/toc-<course>.json`; the course
  home and hub pages filter on it, tolerating an unstamped cached toc. Algebra I claims 8
  chapters and 43 lessons everywhere outward-facing; the syllabus prose says more is coming.

## Traps that cost hours, so they cost the next session nothing

- Meta's Test Events button opens the site without a test code, so the panel stays empty
  forever. Verify events in DevTools Network (filter `facebook`, the beacon URL is
  `/tr/?...` so filtering `tr?` matches nothing) or in the dataset Overview, which lags up
  to 30 minutes.
- `fbq` exists as a queue stub even when blocked. The real library reports a version like
  2.9.x; version `2.0` plus `transferSize 0` on fbevents.js means an ad blocker ate it.
- The founder opt-out (`qa_internal`) survives sign-out and blocks ALL tracking including
  the pixel. When he says "I see nothing", check that flag first.
- firebase.json ignore entries need `/**`; a bare directory name ignores only the entry.
  `.git`, a 341MB venv, and the tutor worker all shipped to production this way.
- Firestore rules OR together across matching statements; a broad `users/{uid}/{document=**}`
  allow silently re-opens anything a narrower rule denies. Replace whole rule files.
- The founder's zsh corrupts some tool flags (grep, unzip report unknown options they were
  not given). When a shell command fails strangely, use python3 instead.
- Stripe refunds keep the processing fee (~75 cents), and refunding does not cancel a
  subscription; both acts are needed.
