Prealgebra · Lesson 10.4

Counting Pairs

Solve this lesson, free →All lessons

When order matters, multiply straight across. But when picking a pair, like two people shaking hands or two teammates, order doesn't matter, and a straight multiply counts every pair twice.

Problem
Six friends each shake hands once with every other friend. How many handshakes happen in all?
Show a hint
  • A handshake is a PAIR of friends, and the pair Ana with Ben is the same handshake as Ben with Ana, so the order does not matter. And everyone comes from the one group of six friends, not from two separate groups. So this is a pair count, where you will want to watch out for counting each handshake twice.
  • Set up the count the easy way first. Each of the \(6\) friends reaches out to the other \(5\) friends, so multiply to get \(6 \times 5\). Now ask yourself the key question for pairs, did that count each handshake once, or did it sneak each one in twice?
  • You have \(6 \times 5 = 30\), but every handshake got counted twice, once from each friend in the pair. So the honest count is half of \(30\), and all that is left is to take that half.
Show the full solution
A handshake is really just an unordered pair of friends, where Ana shaking Ben's hand is the same single handshake as Ben shaking Ana's hand. So this is a pair count, and everyone comes from the one group of six friends. \nLet us count the easy way first and fix the trouble after. Each of the \(6\) friends shakes hands with the other \(5\) friends, and multiplying those gives $$6 \times 5 = 30.$$ \nBut look closely, because that \(30\) counts every handshake twice. When Ana reaches out to Ben we count it once, and when Ben reaches out to Ana we count the same handshake again. Each pair got tallied from both sides, so the count is doubled. \nThe honest answer is half as big, so we divide by \(2\) to undo the overcount, which gives $$30 / 2 = 15.$$ \nSo the six friends share \(\boxed{15}\) handshakes.
Problem
In an 8-player round-robin tournament, every pair of players meets exactly once. How many matches are played?
Show a hint
  • Think about what one match really is. It is a pair of two players, and the match where Ana plays Ben is the same match as the one where Ben plays Ana, so order does not matter. And notice that both players come from the one group of \(8\), not from two separate groups.
  • Each of the \(8\) players could face any of the other \(7\), so multiply to get \(8 \times 7\). Now ask the key question, since both players come from the same group, does counting this way count each match once or twice, and if it is twice then you will need to divide by \(2\).
  • You have \(8 \times 7 = 56\), and every match got counted twice because each pair shows up from both players' points of view. So take half of \(56\) and you are there.
Show the full solution
Every match is just a pair of players, so we are choosing \(2\) players from the \(8\), where order does not matter since Ana playing Ben is the same match as Ben playing Ana. Start with the multiplying habit. Each of the \(8\) players can face any of the other \(7\), which gives \(8 \times 7 = 56\). But that counts each match twice, once from each player's side, so we undo the overcount by dividing by \(2\). That gives $$\frac{8 \times 7}{2} = \frac{56}{2} = 28.$$ Since both players come from the same group of \(8\), the divide-by-\(2\) is exactly what keeps us honest, and we land on \(\boxed{28}\) matches.
Problem
\(4\) students volunteer and exactly \(2\) work together each day. No pair repeats. How many days at most can be scheduled?
Show a hint
  • Two students working together is a PAIR, and the order does not matter, since Ana with Ben is the same team as Ben with Ana. And notice all four come from one single group of volunteers, not two separate groups.
  • Each student can be paired with the other \(3\), so reach for the multiplying habit and you get \(4 \times 3\). But every pair gets counted twice that way, so think about whether you should divide by \(2\).
  • You have \(\frac{4 \times 3}{2}\), which is \(\frac{12}{2}\). The most days is just how many different pairs there are, so finish the division.
Show the full solution
Each day puts a different pair of students together, and no pair ever repeats, so the most days you can schedule is simply the number of different pairs you can make. To count the pairs, think of each of the \(4\) students reaching out to the other \(3\), which gives \(4 \times 3 = 12\). But that counts every pair twice, once from each person's side, since Ana with Ben is the same team as Ben with Ana. So the honest count is half as big and you divide by \(2\), which gives $$\frac{4 \times 3}{2} = \frac{12}{2} = 6.$$ There are \(6\) different pairs, so the greatest number of days that can be scheduled is \(\boxed{6}\).
Problem
An ice cream shop has \(11\) flavors. A double scoop uses \(2\) different flavors, order doesn't matter. How many different double scoops are possible?
Show a hint
  • First decide what kind of count this is. You are choosing \(2\) flavors from one single list of \(11\), and a scoop of chocolate on vanilla is the same scoop as vanilla on chocolate. So this is a pair where the order does not matter, and both flavors come from the same group, not two separate groups.
  • Set it up like a handshake. The first flavor has \(11\) choices and the second has \(10\) left, so a first pass gives \(11 \times 10\). But picking chocolate then vanilla and picking vanilla then chocolate land on the same double scoop, so each scoop got counted twice. That tells you whether to divide by \(2\) here.
  • You have \(\frac{11 \times 10}{2}\) to finish. Work out the top first, then take half of it, and you have your count.
Show the full solution
A double scoop is just an unordered pair of flavors, because a scoop of mint on top of strawberry is the exact same dessert as strawberry on top of mint. So this is the handshake idea again, and we count pairs from one group of \(11\). Start the way we multiply in 10.2. The first flavor can be any of the \(11\), and once it is chosen the second flavor can be any of the \(10\) that are left, and you get $$11 \times 10 = 110.$$ But watch the same trap as the handshakes. Choosing chocolate first and vanilla second gives the same double scoop as choosing vanilla first and chocolate second, so every scoop has been counted twice. To undo that overcount we take half, which gives $$\frac{11 \times 10}{2} = \frac{110}{2} = 55.$$ So there are \(\boxed{55}\) different double scoops.
Key idea
Count ordered, then halve. The number of unordered pairs from $n$ things is $\frac{n(n-1)}{2}$. Count the ordered way first, from the Multiplication Principle, with $n$ choices for the first pick, then $n-1$ left for the second, giving $n(n-1)$. But every pair got counted twice, once as A then B and once as B then A, the same handshake both times, so divide by $2$. A handshake, a round-robin match, a team of two, a double scoop. Each is just a pair pulled from one group of $n$.
Problem
A dance class has \(7\) leaders and \(6\) followers. Every leader dances once with every follower. How many dances take place?
Show a hint
  • Before you count anything, ask what kind of pairing this is. A dance joins one leader with one follower. Are those two coming from the same group, where order would not matter, or are they coming from two different groups you can tell apart?
  • You are pulling one pick from the leaders and one pick from the followers, two separate groups, so multiply their sizes. Then pause and decide whether you need to divide by \(2\) the way you do when both picks come from one group.
  • Multiplying gives \(7\times6\), and since a leader and a follower can never trade roles, no dance gets counted twice, so there is no dividing by \(2\) here. Just finish that one product.
Show the full solution
Each dance pairs one leader with one follower, and those two picks come from TWO different groups, the leaders and the followers. When the picks come from groups you can tell apart, you simply multiply the sizes, so $$7\times6=42.$$ Notice there is no dividing by \(2\) this time. We divide by \(2\) only when both picks come from the same group, because then choosing Ana then Ben is the same pair as choosing Ben then Ana. Here a leader and a follower can never swap roles, so no dance is ever counted twice and nothing needs undoing. The number of dances is \(\boxed{42}\).
Problem
At a party, \(5\) women shake hands with every other person, but the \(4\) men never shake hands with each other. How many handshakes take place?
Show a hint
  • A handshake is just a pair of people, and the order does not matter, since you shaking my hand is the same single handshake as me shaking yours. So really you are counting how many allowed pairs there are. Notice the pairs come in different kinds, some join two women, some join a woman and a man, and some would join two men.
  • Split the count into kinds of pairs. For two women, both come from the same group of \(5\), so that is a pair where you reach out and then divide by \(2\). For a woman and a man, the two picks come from different groups, so you just multiply the sizes and do not divide. For two men, none are allowed, so that kind adds nothing.
  • You should have woman-with-woman giving \(\frac{5 \times 4}{2}\), woman-with-man giving \(5 \times 4\), and man-with-man giving \(0\). Work each one out, then add the three counts together.
Show the full solution
A handshake is a pair of people, and order does not matter, so all we are really doing is counting the allowed pairs. The pairs come in different kinds, so let us split them up and count each kind on its own. \nFirst the woman-with-woman handshakes. Both people in such a pair come from the same group of \(5\) women. Each woman could reach out to the other \(4\), and you get \(5 \times 4\), but that counts Ana-with-Bea and Bea-with-Ana as two different things when they are the same handshake. So we divide by \(2\) to undo that double count, which gives \(\frac{5 \times 4}{2} = 10\). \nNext the woman-with-man handshakes. Now the two people come from groups you can tell apart, one woman and one man, so nothing gets counted twice and there is no dividing by \(2\). You simply multiply the sizes, which gives \(5 \times 4 = 20\). \nLast the man-with-man handshakes. The rule says no two men shake hands, so this kind adds nothing at all, a flat \(0\). \nNow add the kinds together, and you get \(10 + 20 = 30\). $$\boxed{30}$$
Key idea
One group or two, and what is not allowed. When both picks come from the same group, every pair is counted twice, so divide by $2$ to get $\frac{n(n-1)}{2}$. When you pick one from each of two groups you can tell apart, the picks can never swap, so nothing doubles, and you just multiply the sizes. And when some pairs are off limits, either count all pairs and subtract the forbidden ones, or split the pairs into kinds, count each kind on its own, and add.
Problem
A hexagon has \(6\) corners and \(6\) sides. How many diagonals does it have?
Show a hint
  • Every line in this picture joins two corners, so you are choosing a pair of corners where the order does not matter. All \(6\) corners come from one single hexagon, not two separate groups, so this is a pairs question and not a multiply-the-two-sizes question.
  • First count how many pairs of corners there are at all. Each of the \(6\) corners reaches out to the other \(5\), which gives \(6 \times 5\), and then you divide by \(2\) because joining corner A to corner B is the same line as joining B to A.
  • Once you know there are \(15\) pairs of corners in all, remember that some of those lines are sides, not diagonals. The hexagon has \(6\) sides, so take those away from the \(15\) and you are left with just the diagonals.
Show the full solution
Start with a friendly idea. Every pair of corners in the hexagon is joined by a line, and that line is either a side or a diagonal, never both. So if you count all the pairs of corners first, the diagonals are just what is left after you take the sides away. Count the pairs of corners. Each of the \(6\) corners can reach out to the other \(5\) corners, and that gives \(6 \times 5\). But joining corner A to corner B is the same line as joining corner B to A, so every pair got counted twice. Divide by \(2\) to undo that double count, which gives $$\frac{6 \times 5}{2} = 15.$$ So there are \(15\) pairs of corners in all. Of these, \(6\) of the lines are the sides of the hexagon, and a side is not a diagonal. Take those away and the diagonals are $$15 - 6 = 9.$$ So the hexagon has \(\boxed{9}\) diagonals.
Problem
A decagon has \(10\) corners and \(10\) sides. How many diagonals does it have?
Show a hint
  • Every diagonal joins two corners, and the order you name them in does not matter, so this is a pair where Ana to Ben is the same as Ben to Ana. And all the corners live in one single group, so you will count pairs from that one group rather than multiply two different sizes.
  • Count the pairs of corners first. Each of the \(10\) corners can reach the other \(9\), which gives \(10 \times 9\), and since each pair got counted twice you divide by \(2\). That total includes the sides though, so afterward you will need to take the sides back out.
  • You should have \(\frac{10 \times 9}{2} = 45\) pairs of corners. Now just remove the \(10\) that are sides and not diagonals.
Show the full solution
Start by counting every pair of corners, since each pair gives one straight segment joining them. There are \(10\) corners, and each one reaches out to the other \(9\), which gives \(10 \times 9\). But Ana to Ben and Ben to Ana are the same segment counted twice, so you divide by \(2\) and you get $$\frac{10 \times 9}{2} = 45.$$ Those \(45\) segments include the \(10\) sides of the decagon, and sides are not diagonals. So take them back out, which gives \(45 - 10 = 35\). The decagon has \(\boxed{35}\) diagonals.
Key idea
Diagonals of a polygon. A polygon with $n$ corners has $\frac{n(n-1)}{2} - n$ diagonals. Every line joining two corners is either a side or a diagonal, never both. There are $\frac{n(n-1)}{2}$ pairs of corners in all, and exactly $n$ of them are sides, one per edge, so the rest are diagonals. Count every pair the easy way and subtract the few you do not want.
Problem
Six players each play every other player exactly \(3\) games. How many games are played in all?
Show a hint
  • First decide what you are really counting. A game is played by a pair of people, and the pair Ana with Ben is the same matchup as Ben with Ana, so order does not matter here. And the two players come from the same group of six, not two separate groups, which is the clue that this is a pair where you will need to undo a double count.
  • Count the pairs first. Each of the \(6\) people could face each of the other \(5\), which gives \(6 \times 5\), but that counts every matchup twice since Ana with Ben and Ben with Ana are the same game, so divide by \(2\). Then think about what each pair does after that.
  • You have found that there are \(\frac{6 \times 5}{2} = 15\) pairs. Each pair plays \(3\) games, so the last step is to multiply \(15\) by \(3\).
Show the full solution
Start by counting the matchups, since each game is played by a pair of players. Each of the \(6\) people reaches out to the other \(5\), which gives \(6 \times 5 = 30\). But that counts every matchup twice, because Ana playing Ben is the same pairing as Ben playing Ana, so divide by \(2\) to undo the overcount and you get $$\frac{6 \times 5}{2} = 15$$ pairs of players. Now bring in the part that makes this more than a plain pair count. Each pair does not play once, it plays \(3\) games, so multiply the number of pairs by the games per pair, which gives $$15 \times 3 = 45.$$ So the tournament has \(\boxed{45}\) games in all.
Problem
A 17-player round-robin has \(\frac{17 \times 16}{2} = 136\) matches. Verify this by computing the sum \(1+2+3+\cdots+16\) using the Gauss pairing shortcut. What is the value of this sum?
Show a hint
  • You are adding up the whole numbers from \(1\) all the way to \(16\). This is the same total as the number of pairs you can choose from \(17\) players, since order does not matter and Ana versus Ben is the same match as Ben versus Ana.
  • You could add straight across, but there is a faster way. Try folding the staircase in half. Pair the smallest term with the largest, then the next smallest with the next largest, and notice that every pair makes the same total.
  • Pairing the ends gives \(1 + 16 = 17\), \(2 + 15 = 17\), and so on down to \(8 + 9 = 17\). Count how many pairs of \(17\) you have, then multiply.
Show the full solution
This is the triangular-number way of counting pairs. Instead of adding \(1 + 2 + 3 + \cdots + 16\) term by term, fold the staircase in half the way Gauss did and pair the terms from the ends. The smallest plus the largest gives \(1 + 16 = 17\), the next pair gives \(2 + 15 = 17\), and you keep going inward down to \(8 + 9 = 17\). Every pair sums to the same \(17\). There are \(8\) of these pairs, since \(16\) terms split into \(8\) cozy couples, which gives $$8 \times 17 = 136.$$ This matches the pair-counting formula straight away, because choosing a pair from \(17\) players is \(\frac{17 \times 16}{2} = 136\). Two roads, one answer, and the adding road shows you that counting pairs is really just stacking up \(1 + 2 + \cdots + (n-1)\). So the sum is \(\boxed{136}\).
Fun fact
The pair counts \(1, 3, 6, 10, 15, \ldots\) are called triangular numbers because they equal the number of dots that tile a perfect triangle, \(1\) on top, then a row of \(2\), then \(3\), and so on.
Key idea
Repeats, and the triangular staircase. When every pair does the same thing $k$ times, count the pairs first with $\frac{n(n-1)}{2}$, then multiply by $k$. And counting pairs is also the sum $1 + 2 + \cdots + (n-1)$. Bring people in one at a time and the second makes $1$ new pair, the third makes $2$, and so on. So $\frac{n(n-1)}{2}$ and $1 + 2 + \cdots + (n-1)$ are the same number written two ways, and you can add that sum quickly by pairing the ends the way Gauss did.
Problem
A league has \(12\) teams in two divisions of \(6\). Every team plays every division-mate twice and every team in the other division once. How many games are in the full season?
Show a hint
  • Sort the games into two kinds, the ones inside a division and the ones across the divisions. Inside a division, a game is a PAIR of teams from one group where order does not matter, so Ana versus Ben is the same game as Ben versus Ana. Across the divisions you are picking one team from each of two groups you can tell apart, which is a different kind of count.
  • For one division, first count the pairs with \(\frac{6 \times 5}{2}\), then remember each pair plays twice, and there are two divisions. For the across games, you do not divide by \(2\), since the two teams come from groups you can tell apart, so just multiply the sizes \(6 \times 6\).
  • One division gives \(\frac{6 \times 5}{2} = 15\) pairs, doubled is \(30\), and two divisions make \(60\). The across games are \(6 \times 6 = 36\). Now add \(60\) and \(36\).
Show the full solution
Split the season into two kinds of games, the ones inside a division and the ones across the divisions. Start inside one division. A game there is a pair of teams where order does not matter, so the number of pairs is \(\frac{6 \times 5}{2} = 15\). Each of those pairs plays twice, which gives \(15 \times 2 = 30\) games in that one division. There are two divisions just like it, so that part is \(30 \times 2 = 60\). Now the across games. Here you pick one team from one division and one team from the other, and those are two groups you can tell apart, so nothing gets double counted and you never divide by \(2\). Each of the \(6\) teams plays each of the other \(6\) once, which gives \(6 \times 6 = 36\). Add the two kinds together and you get \(60 + 36 = 96\). $$\boxed{96}$$
Problem
An icosahedron has \(12\) vertices and \(30\) edges. Each face is a triangle. How many interior diagonals does it have?
Show a hint
  • A segment just needs two corners, and swapping which corner you name first gives the same segment, so this is a pair where order does not matter, all coming from one group of \(12\) vertices.
  • Start by counting every pair of vertices, multiply \(12\) by \(11\) and divide by \(2\) since each segment got named twice. Then think about which of those pairs you do not want, the ones that sit on a common face.
  • All pairs come to \(\frac{12 \times 11}{2} = 66\). Every face is a triangle, so the only pairs sharing a face are the \(30\) edges. Now you just have \(66\) and \(30\) waiting to be combined.
Show the full solution
A diagonal is a segment, and a segment is just two corners chosen together, where it does not matter which one you name first. So this is a pair count from the one group of \(12\) vertices. Start by counting all the pairs of vertices you could possibly join. Each of the \(12\) vertices can reach out to the other \(11\), and then you divide by \(2\) so that joining Ana to Ben and joining Ben to Ana count as one segment, which gives $$\frac{12 \times 11}{2} = 66.$$ That \(66\) counts every segment, but we only want the interior ones. So we remove the pairs that lie on a common face. Here is the lovely part. Every face is a triangle, and a triangle has no diagonals of its own, so the only vertex-pairs that share a face are the ones that are actual edges of the solid. There are \(30\) edges, so there are \(30\) pairs to take out. Taking those out leaves $$66 - 30 = 36.$$ So an icosahedron has \(\boxed{36}\) interior diagonals.

Show the solution
A match is a pair of players, so we are counting pairs from one group of \(13\). Start the way we always do, by letting each player reach out to everyone else. Each of the \(13\) players faces the other \(12\), and multiplying gives \(13 \times 12 = 156\). To undo that double count we cut the total in half, so we divide by \(2\) and get $$\frac{13 \times 12}{2} = 78.$$ So the tournament has \(\boxed{78}\) matches.

Practice
A league has \(8\) teams in two divisions of \(4\). Every team plays each division-mate twice and each team in the other division once. How many games are in the season?
Show the solution
There are really two different kinds of games here, so let us count each kind on its own and add them at the end. \nFirst the games inside a division. A game between two teams in the same division is just a pair of teams, and the order does not matter, since playing team A against team B is the same game as team B against team A. With \(4\) teams in a division, the number of pairs is $$\frac{4 \times 3}{2} = 6.$$\nEach of those pairs meets twice, so one division has \(6 \times 2 = 12\) games. There are two divisions built the same way, so the inside games total $$12 + 12 = 24.$$ \nNow the games across the divisions. Here you pick one team from the first division and one team from the second division. These come from two groups you can tell apart, so nothing gets double counted and you do not divide by \(2\), you simply multiply the sizes and you get $$4 \times 4 = 16.$$ \nThe inside games and the across games never overlap, so we add them and you get $$24 + 16 = 40.$$ \nSo the season has \(\boxed{40}\) games.
Practice
Find the sum \(2 + 4 + 6 + \cdots + 28\) (the first 14 even numbers) using the Gauss pairing trick.
Show the solution
Instead of adding the numbers one slow step at a time, let us pair them from the ends, the same folding move that made counting pairs so friendly. Walk in from both sides at once. The smallest and the largest team up first, and you get \(2 + 28 = 30\). The next ones in are \(4\) and \(26\), and you get \(4 + 26 = 30\) again. Keep going, \(6 + 24 = 30\), and the same total keeps coming up.\nEvery pair lands on \(30\), which is the nice part. There are \(14\) numbers in the list, and folding them in half makes \(7\) pairs. So you have \(7\) pairs that each add to \(30\), which gives $$7 \times 30 = 210.$$\nThat is exactly the Gauss staircase shortcut. You can also see it as \(14 \times 15 = 210\), since the average of the two ends times the count gives the same total. So the sum is \(\boxed{210}\).
Practice
A cube has \(8\) vertices, \(12\) edges, and \(6\) square faces (each with \(2\) face diagonals). How many interior diagonals does it have?
Show the solution
Start by joining corners with no rules at all. Any line that joins two of the cube's corners comes from choosing a pair of vertices, and since starting at one corner or the other gives the same line, order does not matter. With \(8\) vertices the number of pairs is $$\frac{8 \times 7}{2} = 28.$$ So there are \(28\) lines joining corners in total. Now we sift out the ones that are not interior. Some of those pairs are edges of the cube, and a cube has \(12\) edges, so we take those away. Some other pairs run straight across a face, and each square face has \(2\) face diagonals, so across the \(6\) faces that is \(6 \times 2 = 12\) face diagonals to take away as well. What is left after removing the edges and the face diagonals must be the lines that pierce the inside, which gives $$28 - 12 - 12 = 4.$$ So a cube has \(\boxed{4}\) interior diagonals.
Practice
A pizza shop offers \(20\) toppings. A 2-topping pizza uses two different toppings, order doesn't matter. How many different 2-topping pizzas are possible?
Show the solution
Picking two different toppings from one list of \(20\), where order does not matter, is exactly a count of pairs. Think of it the way we counted handshakes. Each of the \(20\) toppings can join with any of the other \(19\), which gives \(20 \times 19\) ordered picks. But choosing mushroom then onion makes the same pizza as onion then mushroom, so every pizza has been counted twice. To honestly count each pizza once you divide by \(2\), and you get $$\frac{20 \times 19}{2} = \frac{380}{2} = 190.$$ So there are \(\boxed{190}\) different 2-topping pizzas.
Practice
A heptagon has \(7\) corners and \(7\) sides. How many diagonals does it have?
Show the solution
A diagonal joins two corners, and the line from one corner to another is the same line no matter which corner you name first, so every diagonal is really a pair of corners where order does not matter. That is exactly a pair-counting job. With \(7\) corners, the number of ways to choose a pair is \(\frac{7 \times 6}{2} = 21\), where you multiply because each of the \(7\) corners reaches out to the other \(6\), and you divide by \(2\) because that count sees each pair twice. So there are \(21\) lines joining corners in all. But not every such line is a diagonal. The \(7\) sides of the heptagon also join two corners, and we do not want to count those. So we take all the corner pairs and subtract the sides, which gives \(21 - 7 = 14\). The heptagon has \(\boxed{14}\) diagonals.
