Algebra I · Lesson 2.6

Expressions with Many Variables

Solve this lesson, free →All lessons

The 2.5 toolkit does not change when more than one letter is in view. Take \(8ab+9ab\). The coefficients add the 2.4 way, \(8+9=17\), so \(8ab+9ab=17ab\), and the \(ab\) rides along untouched. That leaves one question for this lesson to answer. A term can now carry several letters, so what counts as the same kind of term?

Problem
Combine \(7st+6st\) into one term. Type its coefficient.
Show a hint
  • \(st\) is one variable part, so this is a single family.
  • Add the coefficients, the 2.4 way.
Show the full solution
The only pull is to fuss over the two letters, but \(st\) is a single family here, so the coefficients simply add the 2.4 way, \(7+6=\boxed{13}\).
Key idea
A single term can multiply several letters. Terms like \(ab\), \(2mn\), and \(5rst\) are one term each, a coefficient times a product of letters. Because multiplication reorders freely, the 1.3 move, the order of the letters inside a term does not matter. So \(ab\) and \(ba\) are the same term, and \(mn\) and \(nm\) are the same term.
Key idea
Like terms match the whole variable part. Two terms are like only when their entire variable part is identical, every letter and its power. So \(4jk\) and \(9jk\) are like and combine to \(13jk\), but \(4jk\) and \(4j\) are unlike, and \(4jk\) and \(4j^2k\) are unlike, since \(j^2\) means \(j\cdot j\), the 1.5 reading. Here is why the whole part has to match. If an illegal merge like \(6ab+4a=10ab\) were true, the two sides would agree at every input, the 1.4 test, and they do not. The figure shows this as tile shapes.
Problem
A classmate rewrote \(5cd+5c\) as \(10cd\), adding the coefficients as if the terms matched. Evaluate the original \(5cd+5c\) at \(c=2,\ d=4\). Type the value.
Show a hint
  • Are \(5cd\) and \(5c\) really like terms? Compare their variable parts.
  • Put \(c=2,\ d=4\) into the original \(5cd+5c\), one letter at a time.
Show the full solution
Adding the coefficients treats \(5cd\) and \(5c\) as like, but their variable parts differ. The original gives \(5\cdot2\cdot4=40\) and \(5\cdot2=10\), so \(40+10=50\), while \(10cd=80\); one input with two outputs proves them unlike, \(\boxed{50}\).
Key idea
Combine one family at a time. To simplify, sweep the expression once for each distinct variable part, add the coefficients in that family, and let the variable part ride along unchanged. This is the 2.4 count with more letters in view. Subtraction still flips the whole term it sits on, so a \(-3wv\) reads as \(-3\) in the \(vw\) family once you use \(wv=vw\) from 1.3.
Problem
Simplify \(11mn+9m-5nm\) by combining like terms. Type the coefficient of the \(mn\) term.
Show a hint
  • \(nm\) is the same variable part as \(mn\), so the order does not matter.
  • The minus travels with its term into the \(mn\) family; the \(9m\) is a different family.
Show the full solution
The trap is skipping \(-5nm\) because it is written backward, or dropping its minus. Read \(nm\) as \(mn\), then \(11mn-5mn=6mn\), and the \(9m\) is a separate family, so \(\boxed{6}\).
Key idea
A distributed factor reaches every term. When a factor that carries a letter multiplies a sum, it multiplies each term inside, the 2.1 move. So \(2h(3k+4m)=6hk+8hm\), the \(h\) joins both products. If the letter fell off one term, the two expressions would disagree on a test input, so the letter has to travel to every term.
Problem
Distribute \(8r(2s+t)\). Type the coefficient of the \(rs\) term.
Show a hint
  • The \(8r\) multiplies every term inside the parentheses.
  • You only need the term that has \(r\) and \(s\).
Show the full solution
It is tempting to multiply only the first term. The \(8r\) reaches both, \(8r\cdot2s=16rs\) and \(8r\cdot t=8rt\), so the \(rs\) coefficient is \(\boxed{16}\).
Problem
Simplify \(2(4uv+5v)+7uv\) by distributing then combining like terms. Type the coefficient of the \(uv\) term.
Show a hint
  • Distribute the \(2\) across both terms inside first.
  • Only the \(uv\) terms combine; the plain \(v\) term is a different family.
Show the full solution
The slip is folding the \(10v\) into the \(uv\) count. Distribute first, \(2(4uv+5v)=8uv+10v\), then only the \(uv\) family combines, \(8uv+7uv=15uv\), so \(\boxed{15}\).
Key idea
Factor out everything shared. The greatest common factor takes the number GCD and every letter that appears in all of the terms, the full scan from 2.3. Pull it to the front, and each leftover keeps its sign. For \(6mn+9mp\) the number GCD is \(3\) and only \(m\) is in both terms, so \(6mn+9mp=3m(2n+3p)\). The \(n\) and \(p\) are not shared, so they stay inside.
Problem
Find the greatest common factor of the terms in \(8pqr+12pqs\), typed like \(2xy\), the number first and the letters in alphabetical order.
Show a hint
  • Take the GCD of \(8\) and \(12\) first.
  • Which letters appear in BOTH terms? Only those come out front.
Show the full solution
Stopping at \(4\) misses the shared letters, and grabbing \(4pqr\) claims one that is not in both terms. The GCD of \(8\) and \(12\) is \(4\), and only \(p\) and \(q\) sit in both, so the GCF is \(\boxed{4pq}\).
Key idea
Substitute one letter at a time. To evaluate a multi-variable expression, replace each letter with its given value, then do the arithmetic, the 1.6 way. A term like \(4mn\) needs both values, \(4\cdot m\cdot n\), so dropping either letter is the common miss. Work one term at a time and the arithmetic stays plain.
Problem
Evaluate \(4gh-2g+h\) at \(g=5,\ h=2\). Type the value.
Show a hint
  • \(4gh\) needs both letters, so \(4\cdot g\cdot h\).
  • Handle the \(-2g\) and \(+h\) after the \(4gh\) term.
Show the full solution
Reading \(4gh\) as \(4g\) drops the \(h\). Substitute both, \(4\cdot5\cdot2=40\), then \(-2\cdot5=-10\) and \(+2\), so \(40-10+2=\boxed{32}\).
Problem
Simplify \(2d(4e+f)+9de\) by distributing and combining, then evaluate the result at \(d=2,\ e=1,\ f=5\). Type the value.
Show a hint
  • Distribute \(2d\) first, keeping the \(d\) on both new terms.
  • Combine the \(de\) terms, then substitute \(d=2,\ e=1,\ f=5\).
Show the full solution
Two traps hide here, dropping the \(d\) while distributing and merging \(de\) with \(df\). Keep \(d\) on both, \(2d(4e+f)=8de+2df\), combine \(8de+9de=17de\), then \(17de=17\cdot2\cdot1=34\) and \(2df=2\cdot2\cdot5=20\), so \(34+20=\boxed{54}\).
Fun fact
Two terms are like only when their whole variable part matches, every letter and its power. A shared coefficient or a single shared letter is not enough, which is why \(4ab\) and \(4a\) never combine.

That caps Chapter 2. Distribute, combine, factor, and evaluate are the whole toolkit, and none of them changed when several letters came into view. Only what counts as a like term widened, the variable part has to match in full. Chapter 3 picks up the other thread, a letter multiplied by itself over and over gets its own shorthand, and the exponents start carrying rules of their own.

Practice these ideas

Practice
Combine \(5jk+9jk\). Type the coefficient.
Show the solution
The only pull is to fuss over the two letters, but \(jk\) is one family, so the coefficients add the 2.4 way, \(5+9=\boxed{14}\).
Practice
Combine \(7gh+8hg\). Type the coefficient.
Show the solution
The trap is treating \(hg\) as a different term because the letters are flipped. Since \(hg=gh\), both sit in one family, \(7+8=\boxed{15}\).
Practice
After combining like terms in \(5mp+2m+4mp\), how many terms remain?
Show the solution
Folding \(2m\) into the \(mp\) count is the miss. The \(mp\) family gives \(5+4=9mp\), and \(2m\) stands alone, so \(\boxed{2}\) terms remain.
Practice
Are \(6ab\) and \(6a\) like terms? Type yes or no.
Show the solution
The shared \(6\) and shared \(a\) tempt a yes, but the variable parts \(ab\) and \(a\) differ, so they are unlike, \(\boxed{\text{no}}\).
Practice
Evaluate \(4pq+3p\) at \(p=2,\ q=5\). Type the value.
Show the solution
Reading \(4pq\) as \(4p\) drops the \(q\). Substitute both, \(4\cdot2\cdot5=40\) and \(3\cdot2=6\), so \(40+6=\boxed{46}\).
Practice
Evaluate \(2mn+4m-n\) at \(m=3,\ n=1\). Type the value.
Show the solution
Dropping the \(n\) from \(2mn\) is the slip. Substitute, \(2\cdot3\cdot1=6\), \(4\cdot3=12\), then \(-1\), so \(6+12-1=\boxed{17}\).
Practice
Distribute \(2a(4b+3c)\). Type the coefficient of the \(ab\) term.
Show the solution
Multiplying only the first term is the trap, but the \(2a\) reaches both, \(2a\cdot4b=8ab\), so the \(ab\) coefficient is \(\boxed{8}\).
Practice
Distribute \(5m(2n+4p)\). Type the coefficient of the \(mp\) term.
Show the solution
It is easy to grab the \(mn\) term instead. The \(mp\) term comes from \(5m\cdot4p=20mp\), so the coefficient is \(\boxed{20}\).
Practice
Simplify \(3r(s+2)+4rs\). Type the coefficient of the \(rs\) term.
Show the solution
Folding the \(6r\) into the \(rs\) count is the slip. Distribute, \(3r(s+2)=3rs+6r\), then only the \(rs\) family combines, \(3rs+4rs=7rs\), so \(\boxed{7}\).
Practice
Factor \(8ab+12ac\) fully. Type the greatest common factor pulled out front, written like \(5x\) (number first, letters alphabetical).
Show the solution
Stopping at \(4\) drops the shared letter, and pulling \(b\) or \(c\) claims one that is not in both. The GCD is \(4\) and only \(a\) sits in both terms, so the GCF is \(\boxed{4a}\).
Practice
Factor \(6cdh+15cdk\) fully. Type the greatest common factor, written like \(2xy\) (number first, letters alphabetical).
Show the solution
Stopping at \(3\) drops the shared letters, and grabbing \(h\) or \(k\) claims one that is not in both. The GCD of \(6\) and \(15\) is \(3\), and both \(c\) and \(d\) sit in every term, so \(\boxed{3cd}\).
Practice
Evaluate \(5st-2s+t\) at \(s=2,\ t=3\). Type the value.
Show the solution
Reading \(5st\) as \(5s\) drops the \(t\). Substitute, \(5\cdot2\cdot3=30\), \(-2\cdot2=-4\), \(+3\), so \(30-4+3=\boxed{29}\).
